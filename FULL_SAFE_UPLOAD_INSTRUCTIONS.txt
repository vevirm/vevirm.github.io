R&I × GEOPOLITICS RADAR — SIMPLE INSIGHTS V6
=============================================

THIS PACKAGE UPDATES THE EXISTING LIVE REPOSITORY.

IMPORTANT: radar.json is intentionally NOT included.
Do NOT delete the existing live radar.json before uploading this package.
That preserves the accumulated radar corpus. If this is used for a completely
new repository, the first scanner run will create radar.json.

THE REPOSITORY NOW HAS TWO VIEWS
--------------------------------
1. /           = the existing full radar
2. /insights/  = the radar classified by topic, one concise bullet per item

The old /briefing/ address only redirects to /insights/.

INSIGHTS CONTAINS ONLY
----------------------
Topic heading
- one-point bullet
- one-point bullet

No sources, dates, links, Strand labels, anchors, relevance metadata, counts,
tags, cards, evidence panels or methodology text are shown.

HOW IT WORKS
------------
insights/index.html reads the same live radar.json used by the main radar.
Every admitted A/B/C item is assigned to one primary topical bucket. The page
then extracts one short understandable point from that radar item. There is no
briefing.json and no briefing-generation workflow.

SCANNER SAFETY
--------------
scripts/scan_radar.py, radar_config.json and .github/workflows/radar-scan.yml are
unchanged. The working scanner continues to update radar.json normally.

UPLOAD
------
1. Extract this ZIP.
2. Upload/replace everything inside it at the root of vevirm/radar_articles_reports.
3. Make sure the hidden .github/workflows/radar-scan.yml file is uploaded.
4. Do NOT delete the existing radar.json.
5. Commit to main.

AFTER GITHUB PAGES DEPLOYS
--------------------------
Open:
https://vevirm.github.io/radar_articles_reports/insights/?v=6

If an old /briefing/ bookmark is opened, it redirects to the new /insights/ page.
