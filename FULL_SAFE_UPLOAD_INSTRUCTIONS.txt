R&I × GEOPOLITICS RADAR — FULL SAFE REPOSITORY V5
==================================================

THIS PACKAGE IS FOR UPDATING THE EXISTING LIVE REPOSITORY.

IMPORTANT: radar.json is intentionally NOT included.
Do NOT delete the existing live radar.json before uploading this package.
That preserves the accumulated Strand A/B corpus and current Strand C material.

WHAT CHANGED
------------
Radar Insights is now only a simple topic-and-bullets page.
It reads the live radar.json directly. There is no briefing.json dependency and
no builder that can regenerate the old complicated page.

Visible Insights content is only:
- topic heading
- short bullet
- short bullet

Topics include Raw materials, Research, AI, Semiconductors & quantum, Energy,
Security & defence, Trade & industry, Digital & cyber, Space, Health & biotech,
Talent & skills, International partnerships, Foresight and Other when needed.

NOT SHOWN ON INSIGHTS
---------------------
- sources
- dates
- links
- Strand labels
- anchors
- relevance metadata
- topic counts
- tags
- evidence panels
- methodology panels

SCANNER SAFETY
--------------
scripts/scan_radar.py, radar_config.json and .github/workflows/radar-scan.yml are
unchanged from the previous safe package. The normal scanner still updates only
radar.json and requests a GitHub Pages rebuild.

The file .github/workflows/radar-briefing.yml is now publish-only. It does not
build or overwrite the Insights page. It only asks GitHub Pages to refresh.

UPLOAD
------
1. Extract this ZIP.
2. Open the GitHub repository vevirm/radar_articles_reports.
3. Upload/replace EVERYTHING inside the extracted folder in the repository root.
4. Preserve the hidden .github/workflows folder.
5. Do NOT delete radar.json.
6. Commit to main.

CHECK AFTER UPLOAD
------------------
Open briefing/index.html on GitHub. Near the top it must contain:

    <h1>Radar insights</h1>
    Signals from the main radar, grouped by topic.

It must NOT contain "Radar relevance", "Strand A", topic-count pills or source
metadata in the visible page template.

Then wait for GitHub Pages to rebuild and open:
https://vevirm.github.io/radar_articles_reports/briefing/?v=5

If the browser still shows an old copy, use the ?v=5 address above or hard refresh
once after the Pages deployment finishes.
