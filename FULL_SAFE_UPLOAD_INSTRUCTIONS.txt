RADAR INSIGHTS
--------------
The existing /briefing/ address is now the simple Insights page.
It reads ../radar.json directly. Nothing generates or overwrites it.

The page does exactly this:
- classify each radar item into one primary topic,
- deduplicate the same item across strands,
- extract one clear point from the radar text,
- show one bullet for that point under the topic heading.

It does NOT show sources, dates, Strand labels, evidence, counts, cards,
relevance notes, tags, or long abstracts.

There is intentionally NO:
- .github/workflows/radar-briefing.yml
- scripts/build_briefing.py
