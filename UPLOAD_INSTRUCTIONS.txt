UPLOAD / REPLACE THE REPOSITORY
================================

1. Extract this ZIP.
2. Open vevirm/radar_articles_reports on GitHub.
3. Upload/replace EVERYTHING inside the extracted folder at repository root.
4. Keep the hidden .github/workflows/radar-scan.yml file.
5. Do NOT delete the existing radar.json.
6. Commit to main.

The commit triggers R&I Radar Scan. The scanner remains the existing scanner and
continues to update radar.json every 12 hours.

GitHub Pages should remain:
    Deploy from a branch -> main -> /(root)

After the Pages deployment completes, use:
    https://vevirm.github.io/radar_articles_reports/insights/?v=6

The previous /briefing/ URL redirects to /insights/.
