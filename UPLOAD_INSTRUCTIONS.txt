UPLOAD / REPLACE THE REPOSITORY
================================

1. Extract this ZIP.
2. Open your GitHub repository: vevirm/radar_articles_reports
3. Add file -> Upload files.
4. Upload EVERYTHING inside the extracted folder to the repository root, replacing existing files.
5. Commit directly to main.

CRITICAL CHECK
--------------
After the commit, open the Actions tab.
You must see a workflow named:

    R&I Radar Scan

If you do NOT see it, the hidden .github folder did not upload.
In that case create this file in GitHub:

    .github/workflows/radar-scan.yml

and copy the contents from:

    WORKFLOW_BACKUP/radar-scan.yml

FIRST SCAN
----------
The commit to main triggers the first scan immediately.
This recovery package already seeds the three accepted Strand B publications from the last healthy corpus (2026-08-18 01:52 UTC). The first scan backfills A/B from 2026-04-01, merges those restored B items, and gives Strand C a 7-day first-run lookback.

The scanner also protects future upgrades: if radar.json is ever replaced by an empty/pending template, it searches recent Git history and recovers the strongest populated cumulative A/B corpus before scanning.

The workflow then runs again every 12 hours. Later C scans use a 48-hour overlap.
It can also be run manually from Actions -> R&I Radar Scan -> Run workflow.
